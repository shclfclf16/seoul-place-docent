## 오류와 수정

- 기존 64자리 테이블 이름 조회 문제: `--legacy-hash-tables` 명시적 읽기 옵션으로 해결했습니다.
- 100 MB 예산 초과: 예상대로 실행 차단. 750 MB 누적 한도 내에서만 실조회했습니다.
- 최초 원본 대조 코드의 16진수 대소문자 불일치: BigQuery TO_HEX와 일치하도록 Python 집계도 소문자로 수정했습니다.
  데이터 오류가 아니라 검증 코드 오류였습니다. 이미 받은 실조회 집계와 로컬 원본을 재대조해 전부 일치함을 확인했고 추가 과금 쿼리는 실행하지 않았습니다.
- 최종 데이터 검증 오류: **0건**. 알려진 공란/중복 관계는 그대로 존재하며 공개 승인 대상으로 간주하지 않습니다.
